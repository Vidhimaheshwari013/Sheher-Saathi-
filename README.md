# Sheher Saathi

Sheher Saathi is an AI-powered civic issue intelligence platform that helps cities understand the real problems behind scattered citizen complaints.

Citizens can submit complaints naturally in English, Hindi, or Hinglish, without needing to fill lengthy forms. Using Llama through Groq, the system understands the complaint and extracts important information such as the issue category, location, severity, duration, and affected groups. If critical information is missing, it can ask a relevant follow-up question.

Instead of treating every complaint as a separate ticket, Sheher Saathi uses multilingual embeddings, semantic similarity, and clustering to connect complaints describing the same underlying problem. For example, multiple reports about flooded roads around the same school can be grouped into one larger civic issue.

The platform then uses a transparent priority engine based on factors such as severity, number of related reports, duration, and affected population. This allows authorities to see which issues require greater attention rather than simply looking at the number of complaints.

- Key Features
🗣️ Multilingual Complaint Understanding — English, Hindi, and Hinglish
🤖 AI-powered extraction using Llama + Groq
💬 Intelligent follow-up questions for incomplete complaints
🔗 Semantic similarity to identify related complaints
🧩 Issue clustering to reveal underlying civic problems
🚨 Transparent priority scoring based on real evidence
🧠 Civic Memory to identify recurring problems over time
📈 Civic Pulse to highlight current and rapidly emerging issues
🗺️ Hotspot visualization for authorities
👤 Human verification before AI-generated insights are treated as confirmed
📋 Evidence-grounded summaries of civic issues
What Makes It Different

Most complaint systems store and count individual complaints. Sheher Saathi goes a step further by asking:

“What larger civic problem is hiding behind all these complaints?”

It converts thousands of unstructured citizen reports into connected, explainable civic intelligence that can help authorities identify recurring problems, detect emerging issues, understand their severity, and decide where attention is needed most.

In short: Sheher Saathi doesn't just collect complaints — it finds the patterns behind them.
